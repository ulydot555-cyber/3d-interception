# Перехват 3D — визуализация первого этапа

Интерактивная страница воспроизводит **результаты исходной Python-модели**, не пересчитывая оптимизацию в браузере.

## Использование

1. Откройте `index.html` в современном браузере (интернет не нужен).
2. Выберите «Прямая» или «Кривая», нажмите «Пуск» или перемещайте ползунок времени.
3. Вращайте 3D-сцену мышью; включите флажок «120 испытаний», чтобы увидеть положения цели при случайных ошибках прогноза.

## Размещение на GitHub Pages

1. Создайте новый **публичный** репозиторий на GitHub.
2. Добавьте `index.html` в корень репозитория (можно также добавить этот README).
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, затем ветку **main** и папку **/(root)**, нажмите **Save**.
5. GitHub покажет ссылку на опубликованный сайт в разделе Pages. Публикация может занять несколько минут.

Не требуется ни сервер, ни Node.js, ни Python на GitHub Pages: Plotly.js встроен в файл.

## Ограничения

- Данные взяты из последнего расчёта модели этапа 1 для скорости цели 14 м/с.
- Пересчёт параметров в браузере не реализован — это визуализация результатов, а не новая физическая модель.
- Камера строится в качестве схематического среза угловой области на расстоянии 65% от предельной дальности. Реальная проверка видимости учитывает дальность и углы обзора.
- Крен и тангаж задаются периодическими функциями, а не связаны с динамикой корпуса.
- 40% успехов для прямой и 31,7% для кривой — доля случайных испытаний при данном наборе параметров, а не гарантия реального перехвата.
- Показанные облаком точки испытаний — положение цели в номинальный момент захвата, цвет — успех/неуспех для всей моделируемой траектории.
