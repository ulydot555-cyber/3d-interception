# 3D Interception — интерактивная визуализация и расчётная модель

Интерактивная 3D-страница проекта: **https://ulydot555-cyber.github.io/3d-interception/**

Сайт показывает рассчитанные Python-моделью траектории и не выполняет оптимизацию непосредственно в браузере.

## Структура репозитория

- `index.html` — интерактивная 3D-визуализация.
- `data.json` — результаты последнего расчёта, которые загружает сайт.
- `stage1/colab.ipynb` — итоговый блокнот Google Colab для первого этапа.
- `stage1/model.py` — исходный код расчётной модели.
- `stage1/export_data.py` — повторный расчёт и формирование `data.json` для сайта.
- `stage1/requirements.txt` — зависимости для локального запуска.
- `stage1/README.md` — описание модели, запуск и ограничения.

## Запуск расчётной модели

Откройте `stage1/colab.ipynb` в Google Colab либо запустите локально:

```bash
python -m pip install -r stage1/requirements.txt
python stage1/model.py
```

## Обновление результатов на сайте

После изменения параметров или алгоритма выполните:

```bash
python stage1/export_data.py
```

Скрипт пересчитает модель и обновит `data.json` в корне проекта. Загрузите изменённый `data.json` в репозиторий и создайте commit. После публикации GitHub Pages отобразит новые траектории и показатели.

GitHub Pages не запускает Python: вычисления выполняются локально или в Google Colab, а сайт отображает готовый `data.json`.

## Контрольный результат первого этапа

Для встроенного примера со скоростью цели 14 м/с получена прямая стратегия с номинальным временем захвата около 7,089 с и 1996 успешными испытаниями из 2000 (99,8%). Это оценка в заданной математической модели, а не гарантия для реальной системы.
