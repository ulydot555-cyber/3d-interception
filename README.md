# 3D Interception — сайт, обновляемый через data.json

Этот сайт показывает результаты **готового Python-расчёта**. HTML-файл больше не нужно заменять каждый раз. При открытии сайт загружает свежие данные из `data.json`.

## Первичная установка

1. Загрузите в публичный репозиторий файлы `index.html`, `data.json`, `README.md` и `.nojekyll` из данного архива.
2. Держите файлы в корне ветки `main`. Включённый GitHub Pages будет читать их автоматически.
3. Если `data.json` недоступен, страница откроется со старым резервным набором данных; это будет отмечено справа вверху.

## Как обновлять после изменения Python

1. Отредактируйте локальный `model.py` и выполните скрипт `export_data.py` (из отдельного комплекта для расчётов).
2. Загрузите **только новый `data.json`** в корень репозитория и сделайте `Commit changes`.
3. После публикации обновите сайт в браузере; при необходимости используйте Ctrl+F5.

> Важное замечание: GitHub Pages **не выполняет Python**. Храните алгоритм в приватном репозитории или локально, если не хотите публиковать исходный код.
